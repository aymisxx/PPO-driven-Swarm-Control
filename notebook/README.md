# PPO-Driven Swarm Control - Notebook Pipeline

This directory contains the full end-to-end implementation of a hybrid
multi-robot swarm control pipeline.

## Overview

The pipeline combines:

-   PPO-based local navigation (learned policy).
-   artificial potential fields (geometry and spacing).
-   graph-based consensus (coordination).
-   CRN-inspired role switching (adaptive heterogeneity).

The goal is not to produce a fixed output, but to provide a
**reproducible framework** that can be applied to different input images
and scenarios.

---

## Directory Structure

### 1. `end-to-end-pipeline-author.pdf`

-   Main document (author version).
-   Contains full pipeline explanation, equations, results, and
    interpretation.
-   Recommended starting point for understanding the system.

### 2. `reproducibility_notebook.ipynb`

-   Full executable notebook.
-   Contains all code required to reproduce the pipeline.

To use:
- open the notebook. 
- run cells sequentially.
- outputs will be generated automatically.

### 3. `author_data/`

-   Contains the ai-generated top-down satellite image used by the author.
-   Serves as a **reference input**.

### 4. `author_results/`

-   Contains results generated by the author:
    -   plots.
    -   metrics.
    -   final GIF.

These are **author's outputs**, not fixed targets.

## Running Your Own Experiment

The notebook is designed for **user-driven experimentation**.

### Steps:

1.  Run Section 0 → this creates:

- data/
- results/
- models/
- logs/

2.  Place your own image inside as:

**data/field_satellite.jpg**

3.  Run the notebook from Section 1 onward.

## Important Notes

The pipeline includes stochastic components: 

- PPO policy behavior.
- random spawning.
- role switching.

Therefore:
- results will vary across runs.
- trends should remain consistent.

## Philosophy

This project is not intended to be replayed as a fixed script.

Instead:

The notebook defines a system.
Users are expected to apply it to their own data and observe emergent behavior.
